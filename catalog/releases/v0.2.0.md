Snapshot Inspector 0.2.0 adds a membership preview for creating and updating linked-control schematic pages and native Popups. Retained controls keep their positions, styles and bindings. Obsolete controls are kept by default; explicit removal affects only identified generated controls and preserves captions and annotations. Updates reject stale or ambiguous ownership and use one native document operation.

New pages use the native page background and black model labels. New Popups retain native background defaults. Attachment is handled explicitly for new Popups and controls appended to existing workspaces. This release also adds compressed-payload boundary checks and portable workspace and adapter checks.

Requires Mods Core 0.1.10 or newer within 0.1.x and Mod Manager 0.10.0 or newer. Schematic Tools versions older than 0.17.0 conflict with this mod. Untested Designer builds require installation-specific exact-build consent; consent does not establish compatibility.

The portable regression suite contains 166 checks. Compilation and portable checks do not establish native rendering, history or persistence. Validate workspaces on the Designer build you use. Viewer, connected Core and hardware behavior are outside these checks; this release does not claim Designer 10.5.1 compatibility.
