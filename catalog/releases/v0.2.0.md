Snapshot Inspector 0.2.0 adds a membership preview for creating and updating linked-control schematic pages and native Popups. Retained controls keep their positions, styles and bindings. Obsolete controls are kept by default; explicit removal affects only identified generated controls and preserves captions and annotations. Updates reject stale or ambiguous ownership and use one native document operation.

New pages use the native page background and black model labels. New Popups retain native background defaults. Attachment is handled explicitly for new Popups and controls appended to existing workspaces. This release also adds compressed-payload boundary checks and portable workspace and adapter checks.

Requires Mods Core 0.1.10 or newer within 0.1.x and Mod Manager 0.10.0 or newer. Schematic Tools versions older than 0.17.0 conflict with this mod. Untested Designer builds require installation-specific exact-build consent; consent does not establish compatibility.

Startup verifies the complete inspected 10.5.0 or 10.5.1 host/common pair, the loaded assembly locations, and all drawing, hover and sidebar hook signatures before patching. The 10.5.1 route retains Core's matching installation-specific build consent. Unknown and mixed builds remain rejected.

The portable regression suite contains 229 checks, including 63 startup checks. The release DLL passed targeted normal startup and Inspector opening on Designer 10.5.0 and 10.5.1 with Mods Core 0.1.11. The 10.5.1 run covered corrected-file cold reopening, both workspace no-ops, page and Popup additions with native Undo/Redo, saving and fresh-process reopening, and reopening plus a separate SaveAs without Snapshot Inspector or Mods Core. The 160 recorded native/file comparisons cover audited fields and bindings; they are not independent GUI or physical shortcut tests. Inspector, membership indicators, sidebar actions, the generated page and the visible portion of the Popup received visual spot checks.

Hover information was **not demonstrated** on 10.5.1; six installed hover hooks do not establish displayed hover text. Full tall-Popup rendering and a light/dark matrix on this DLL, stored snapshot payloads/runtime values, injected native attachment failures, uncertain-commit paths, Viewer, connected Core and hardware are outside this acceptance. Earlier 10.5.0 workspace and Popup light/dark checks remain evidence for the unchanged workspace implementation in the preceding build. Recorded-field preservation is not whole-document equivalence, and this release does not claim general Designer 10.5.1 compatibility.
